## 100-PROJECT 二段階運用メモ
1. Phase 1（初期）
`docs/100-PROJECT/101-README_PROJECT.md` を記入して開始する。  
他の `100-PROJECT` 文書は未記入でも開始可。
2. Phase 2（拡張）
API 着手時に `109-API_CONTRACT_POLICY.md` を必須化する。  
実装着手時に `110-NAMING_POLICY.md` と `111-SANITIZE_POLICY.md` を必須化する。  
リリース前に `112-E2E_CHECKLIST.md` を必須化する。
