# 003-GIT.md
# Git運用（正本）

## 原則
- 1孫タスク ≧ 1コミット
- `git add` と `git commit` は分離
- コミット末尾に `#TID` 必須
- 破壊的操作（履歴改変、`git reset --hard`、強制push）禁止
- 最終回答前に `git status --porcelain`

root 例外:
- `AGENTTODO.md` / `AGENTOUTPUT.md` / `MEMORY.md` の bridge 管理コミットのみ可
- 実装差分を含むコミットは禁止

注記:
- `MODE_DECISION`（PLAN/DIRECT）は進行管理ルールであり、Gitコミット規範は変更しない

## コミット形式
```text
type: 変更内容 (#TID-x-x-x)
```

type: `feat|fix|docs|refactor|chore|test`

## コミット前チェック（必須）
1. 差分確認
2. AGENTTODO 状態更新（完了時は `[x]`）
3. `git add ...`
4. `python tools/commit_linter.py --message "... (#TID-x-x-x)" --check-type`
5. `git commit -m "... (#TID-x-x-x)"`

## 完了判定
- 完了＝AGENTTODO 更新を含む最後の対応コミット成功
- `[x]` のみで未コミットは未完了
- 未コミット差分がある状態で完了報告しない
